About CERBERUS x402 Architecture

CERBERUS operates as an x402 resource server gateway. Requests to POST /analyze-contract return HTTP 402 until an on-chain USDC payment transaction is submitted and verified against the Algorand Testnet Indexer. Contract text can be pasted directly or extracted from uploaded documents (PDF, Word, ODT, RTF, HTML, plain text) — client-side via PDF.js/mammoth, with a server-side /extract-text fallback for other formats.
